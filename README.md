# AI应用面板

[打开原资讯面板的只读分享页](https://hunterz998.github.io/ai-panel/share/#sectors)：沿用原有界面和全部公开浏览功能，包括六赛道、全信源、主题快讯、精选、X 雷达、公众号索引、机构研究、公司人物、播客和个人收藏。观点保留支持／削弱条件、依据和出处。无需登录，关闭维护者电脑不影响访问。

[打开互动面板](https://hunterz998.github.io/ai-panel/) · [打开六赛道观察](https://hunterz998.github.io/ai-panel/news.html#sectors)

遇到 403、404 或访问受限时，可以直接在 GitHub [阅读六赛道、资讯与项目研究](https://github.com/hunterZ998/ai-panel/blob/reader/README.md)。阅读页随公开面板同步，标注各份快照的更新时间。

[下载离线互动版](https://github.com/hunterZ998/ai-panel/releases/download/public-reader/panel.html)，保存后用浏览器打开。

分享页由云端发布流程在公开数据同步后执行 `python3 build_share.py` 生成，直接复用 `news.html`，不再采用另外的精简模板。所有读取来自内置公开快照，维护写入一律拒绝；个人收藏仅存访客浏览器。完整 IMA 材料和 Alpha 实时查询仍需私有授权，不包含在分享权限中。“刷新资讯”会重新载入云端最新发布页。自动发布成功不代表每个上游来源都完成了更新，仍以各源时间为准。
