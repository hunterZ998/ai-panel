# AI应用人机台

[打开 AI应用人机台](https://hunterz998.github.io/ai-panel/)：按目的、标准、知识库、判断、策略、执行、复盘及优化组织研究工作。无需登录，关闭维护者电脑不影响访问。

[直接看六赛道](https://hunterz998.github.io/ai-panel/share/#sectors) · [查看三知判断](https://hunterz998.github.io/ai-panel/share/#work-judgment) · [查看采集状态](https://hunterz998.github.io/ai-panel/share/#work-execution?tab=collection)

知识库保留完整的原资讯功能：六赛道、全信源、主题快讯、精选、X 雷达、公众号索引、机构研究、公司人物、中英文播客和本机收藏。判断页保留支持、削弱、仅相关和待核证据，以及出处和判定条件；可继续查看关联核查建议与复盘。策略建议、实际研究行动、后台采集状态分别显示，缺少业务记录时明确说明，不据此编造完成率或收益。

原有项目资料与本机 Excel 入口保留在 [项目资料页](https://hunterz998.github.io/ai-panel/projects.html)，原 `#project/` 链接会自动转到该页面。

遇到 403、404 或访问受限时，可以直接在 GitHub [阅读六赛道、资讯与项目研究](https://github.com/hunterZ998/ai-panel/blob/reader/README.md)。阅读页随公开面板同步，标注各份快照的更新时间。

[下载离线互动版](https://github.com/hunterZ998/ai-panel/releases/download/public-reader/panel.html)，保存后用浏览器打开。

分享页由云端发布流程在公开数据同步后执行 `python3 build_share.py` 生成。`seven-module.js` 和 `seven-module.css` 提供七模块导航，知识库继续使用 `news.html` 的原始研究界面、分类和证据判定功能。下载版与分享页使用同一份文件。

所有读取来自内置公开快照，维护写入一律拒绝；个人收藏仅存访客浏览器。完整 IMA 材料和 Alpha 实时查询仍需私有授权，不包含在分享权限中。“刷新页面”会重新载入云端最新发布页。页面发布时间和各来源最后成功时间分别显示，自动发布成功不代表每个上游来源都完成了更新。
