分享页由云端发布流程在公开数据同步后执行 `python3 build_share.py` 生成。构建只读取公开数据投影，HTML 内不含私有连接、维护凭据或写入接口。自动发布成功不代表每个上游来源都完成了更新，仍以页面显示的各源时间为准。
